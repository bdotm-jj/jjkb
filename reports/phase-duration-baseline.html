Methodology & notes

Inclusion criteria
Only phases with Status = Complete and an end date within the quarter are counted. In-progress or future phases are excluded from averages.
Duration calculation
Days = End Date − Start Date + 1 (inclusive of both endpoints). Calculated from phase-level header rows in each project plan sheet.
Q1 cutoff
March 30, 2026. Projects where phases ended April 1 or later are excluded from Q1 even if the project was nearly complete.
Data source
Smartsheet Project Plans across all lines of business (Commercial Lines, Personal Lines, Motion, Flood, Support Services). 17 projects included in Q1 baseline.
Outlier note
Q1: Alpha Testing and UAT averages elevated by long-running projects (GLISE Lifecycle, Chubb Local Rating). Q2: Chubb Local Rating UAT phase ran 386 days (Jun 2025 – Jun 2026), raising the Q2 UAT avg from 42d to 85d. Exclude this project for a tighter benchmark if needed.
Update schedule
Refreshed monthly. Each cycle pulls newly completed phases whose end date falls within the current quarter, adds them to that quarter's avg column, and rolls the count into the cumulative n and range shown for each phase. Prior quarters' avg values are never recalculated.
Classification tabs scope
The "Phase duration by project classification · Q2 vs Q1 baseline" comparison tabs above are not part of the automated monthly refresh — they still reflect the Jul 2, 2026 snapshot and are not updated with Q3 data. Treat those tabs as a point-in-time Q2 analysis, not a live view. This is now the third consecutive refresh (Jul, Aug 10, Aug 25) in which these tabs have gone stale — they should either be brought into the scheduled task's scope or removed from the report.
