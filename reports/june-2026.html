Key Findings & Recommendations

  • Efficiency improvement: Average total testing duration fell from 8.0d (baseline Nov '25–Mar '26) to 4.8d in the current period — a 40% reduction — suggesting improved defect resolution speed or reduced complexity in recent projects.
  • R1→R2 reduction deepened: The current period shows a 62.5% reduction from R1 to R2 duration, up from 44.2% in baseline. Fewer defects are carrying forward into second rounds.
  • Scottsdale API is an outlier: At 10d for R1 (the longest single-round test this period), it skews the average upward. Without it, the current average drops to ~3.8d. This project may warrant a complexity review.
  • GLISE and RenRe lines are efficient: GLISE Forms API and RenRe Personal Lines both completed in 2d with single rounds — the leanest tests in the dataset, a positive signal for scoped API integrations.
  • Pipeline is building: Several projects with durations but no start dates (Motion HVH API, Moratorium Service, MeshVI, Chubb API) remain in the queue. These will shift the averages once active.
Recommendations
  • Investigate Scottsdale API scope to determine whether the 10d R1 is a recurring pattern or a one-time anomaly; document root cause for future planning.
  • Use Atrium - PL's multi-retest pattern as a process improvement case study — examine what drove 3 rounds and whether earlier defect discovery could reduce cycles.
  • Proactively schedule start dates for the 5 backlog projects (Motion HVH, Moratorium, MeshVI, Chubb API, Markel Artisan Rater) to allow workload forecasting for Q3 2026.
